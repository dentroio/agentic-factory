Optional: continuous deploy (CD) & harness

The factory works end-to-end without CD. Agents, PRs, and CI do not need a deploy runner. CD only rebuilds this engine stack after merges to main.

To enable CD
  1. In GitHub (engine repo) → Settings → Actions → Runners, add a self-hosted runner on the machine that runs Docker.
  2. Give it the label factory-deploy.
  3. Open Settings → Deploy & Harness — when the UI shows the runner online, turn CD on.

That runner is an operator step (GitHub UI). Merging the CD PR does not create it for you.

Harness (separate from CD)

Same settings page: tool policy (what the coding agent may call) and optional weekly spend budget. No deploy runner required. After you save prefs, restart the agent runner so new claims pick them up.
