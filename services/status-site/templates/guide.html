First-time checklist

  1. Open Settings → Get Started — GitHub token, product repo, agent.
  2. Confirm the agent is online on Factory.
  3. Create a WO from New WO or PM View.
  4. When a yellow validation banner appears, verify the change, then Approve or Reject.
  5. Optional harness anytime: Deploy & Harness — tool policy / budget (restart agent after save).
  6. Optional CD: register a self-hosted runner labeled factory-deploy in GitHub, then enable CD on that same settings page. Skip this if you are fine restarting the stack by hand.

Written docs live in the repo wiki (docs/wiki/) and the program backlog (docs/project_management/BACKLOG.md).
